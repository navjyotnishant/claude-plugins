Check this text against the author's writing style: $ARGUMENTS

If nothing was supplied, ask for the file or the text.

Spawn the `editor` agent. It reads the author's style profile (commonly a skill named `my-writing-style`) and treats its hard rules as non-negotiable, then checks for the continuity damage that revision leaves behind.

Return the results in two groups:

**Mechanical fixes**, which you can apply directly: typos, subject-verb agreement, orphan citations, dangling antecedents, duplicate headings, editor chrome pasted from a WYSIWYG tool, and typos in hashtags or proper nouns.

**Voice suggestions**, which the author accepts or rejects. Present these as options rather than corrections. A sentence that reads oddly to an editor is often deliberate, and silently "fixing" the author's voice is the fastest way to make this tool useless to them.

Flag any violation of a hard rule in the style profile prominently and separately. Those are not suggestions.

If the text has been through several rounds of editing, say so and run the continuity check again after any further changes. Continuity errors are generated by revision, so each round can create new ones.
